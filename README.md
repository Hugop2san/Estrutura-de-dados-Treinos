# 🧠 Projeto de Treino C# — Estrutura de Dados e Memória (Heap vs Stack)

Este repositório contém exercícios e anotações voltados para o estudo prático de **estrutura de dados em C#**, com foco especial na compreensão do comportamento de **objetos na heap**, **tipos primitivos na stack**, e **referência vs valor**.

## 📌 Objetivos

- Praticar o uso de `List<T>` para simular um CRUD simples.
- Compreender como a memória funciona ao manipular objetos (`class`) e valores (`struct`, `int`, `double`, etc).
- Explorar o comportamento de referências em listas e funções.
- Aplicar validações com `TryParse`, `IsNullOrWhiteSpace`, entre outros.
- Estudar conceitos básicos de segurança, como o tratamento de dados nulos em entradas do usuário (POST).

## 🔧 O que foi implementado

- Simulação de cadastro de funcionários.
- Validação de entrada com `TryParse`.
- Busca por ID e manipulação segura de objetos.
- Aplicação de aumentos salariais com lógica condicional.
- Demonstração prática da diferença entre **valor** e **referência** em C#.

## 💻 Tecnologias utilizadas

- Linguagem: C#
- Ambiente: Console Application (.NET)
- Editor: Visual Studio Code
